# Изменения

## 0.2.0 — 23 октября 2026

- Добавлен PersonaMem 32k: загрузка двух файлов с фиксацией revision и хешей, разделение по персонам, предъявление вопроса после чтения и оценка выбора варианта.
- Генерацию можно отделить от оценки: `--no-score` и `evaluate`. Оценщик работает по эталонам без вызова модели. Внутренний проверяющий вызов `reflexive` остаётся частью агента.
- Добавлены `smoke`, `--dry-run`, `protocol.json`, `predictions.jsonl`, seed, параметры таймаута и контекста локального сервера. Режимы чередуют порядок между примерами.
- Поддержан локальный OpenAI-совместимый сервер, включая vLLM через SSH-проброс порта.
- Схема ограничивает число ссылок количеством видимых источников. Ошибки формата можно повторить до двух раз через `--format-retries`; по умолчанию повторы отключены. Каждый вызов учитывается и сохраняется на диск.
- Добавлены отчёт по типам вопросов, сравнение до и после поиска, проверка идентичности данных и полноты предсказаний при оценке.
- Добавлены инструкция тестирования, обзор бенчмарков и CI для Windows/Linux, Python 3.11/3.12.

## 0.1.0 — 9 октября 2026

Первая версия: режимы summary/reflexive, JSONL-журнал, ограниченная память, поиск, три демонстрации и BABILong qa1/8k. Локальный запуск Llama 3.2 1B сохранён в `examples/`.
