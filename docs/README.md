# Документы проекта

Для знакомства с результатами откройте [краткий финальный PDF](reports/final/report.summary.pdf) или [HTML-отчёт с каталогом ответов](reports/final/report.html).

| Раздел | Что находится внутри |
| --- | --- |
| [Финальные отчёты](reports/final/README.md) | Краткий PDF, полный PDF и HTML-отчёт |
| [Дополнительный анализ](reports/analysis/babilong_sensitivity.md) | Чувствительность BABILong к форме ответа и разбор несовпадений |
| [Данные отчётов](reports/data/README.md) | Ответы CSV/JSON, доступные промежуточные записи, источники и данные для сборки PDF |
| [Графики](reports/figures/) | Отдельные SVG: точность, повторное чтение, полный контекст и расходы |
| [Методика](methodology/benchmarks.md) | Исследовательский вопрос, наборы данных, адаптация, метрики и ограничения |
| [Инструкции](guides/testing.md) | Установка, запуск, оценка и пересборка отчётов |
| [Проведённые эксперименты](experiments/README.md) | Условия локальной проверки и двух платных серий |
| [Схемы](assets/diagrams/) | Архитектура, сравнение методов, исходники Mermaid и настройки отрисовки |

Исходные результаты, протоколы и доступные журналы находятся в [архиве экспериментов](../examples/README.md). Отчёты отдельных прогонов оставлены рядом с их исходными файлами.

Финальные материалы и вспомогательные данные разделены внутри [раздела отчётов](reports/README.md). Правила пересборки описаны в [инструкции](guides/testing.md#отчёты-и-повторяемость).
