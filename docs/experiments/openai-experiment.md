# Первая платная серия

Серия от 1 ноября 2026 года сравнивает Summary и Reflexive на 48 примерах. Выполнены 512 основных прогонов на трёх моделях и четырёх настройках model/reasoning. Все завершились без ошибок исполнения. Расход с отладкой — $9,37739709.

[Результаты серии](../../examples/openai-20261101/report.md) · [Все ответы и графики](../reports/final/report.html).

## Вопрос и условия

Проверяется, улучшает ли предварительный отбор и последующая проверка сохранность памяти по сравнению с одним обновляющим вызовом. Память обоих методов — 512 токенов. Состояние — 512, окно с резервом — 8192, фрагмент — 2048, выход API — 2048. Размеры приложения измеряются cl100k_base; выход API включает reasoning. Разрешены два повтора при нарушении формата и один поиск до двух фрагментов.

| Профиль | Модель | Reasoning |
| --- | --- | --- |
| 4.1-mini | gpt-4.1-mini-2025-04-14 | Нет отдельного режима |
| 5.4-nano-low | gpt-5.4-nano-2026-03-17 | low |
| 5.4-mini-low | gpt-5.4-mini-2026-03-17 | low |
| 5.4-nano-none | gpt-5.4-nano-2026-03-17 | none |

Используются 16 PersonaMem, 20 BABILong и 12 собственных смен цели. На всех примерах запускаются оба метода; на PersonaMem — ещё полный контекст и последнее окно. Четыре профиля × (16 × 4 + 20 × 2 + 12 × 2) = 512 прогонов.

Конкретный вопрос PersonaMem появляется после истории. BABILong получает вопрос до чтения. В смене цели первая и вторая контрольные точки оцениваются отдельно. Выборка и порядок фиксированы до основной серии. Промпты не перенастраиваются по eval-ответам.

## Оценка

Эталонные ответы не передаются агенту. Оценщик сравнивает букву варианта в PersonaMem и точный короткий ответ в остальных наборах. В знаменателе остаются все назначенные прогоны. Внутренний verify — часть метода, не итоговый судья.

Приведены Wilson-интервалы, парный bootstrap и точный McNemar без поправки на множественные сравнения. На комбинацию выполнен один прогон. Выборки небольшие, поэтому результаты рассматриваются как пилотные.

## Расходы

6 890 запросов основной серии стоили $8,60545639. Ещё 498 отладочных запросов — $0,77194070. Итого 7 388 запросов и $9,37739709. Программный лимит первой серии — $26 из выделенных $28. В продолжении использован тот же журнал расходов.

Перед запросом клиент резервирует сумму в SQLite-транзакции. После ответа резерв заменяется стоимостью по usage. Неопределённые запросы удерживают полный резерв. Учёт включает кеш и reasoning; это не выгрузка баланса аккаунта. Тарифы в протоколе относятся к 1 ноября 2026 года и не являются текущим предложением цены.

## Повторение

Нужны Python с зависимостями, исходные экспорты обоих датасетов и ключ API. Подготовка данных описана в [инструкции](../guides/testing.md). Скрипт `context_memory.study` имеет фазы debug, prepare, run и score. Платный run вызывает модель; назначать его следует только с отдельным явно установленным бюджетом.

Исторические материалы: [protocol.json](../../examples/openai-20261101/protocol.json), [предсказания](../../examples/openai-20261101/predictions.csv), [расходы](../../examples/openai-20261101/receipts.csv). Полные tasks, inputs и SQLite-журнал отсутствуют в клоне. В текущем API-клиенте есть изменения относительно замороженного протокола 0.3. Для точного повтора нужна соответствующая версия реализации, а для нового эксперимента — новый протокол и каталог. Старые данные не перезаписываются.
