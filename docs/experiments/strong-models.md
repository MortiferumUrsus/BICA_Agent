# Продолжение на Sol и Astra

Это вторая группа запусков через API внешнего сервиса моделей с оплатой по обработанным токенам. Она продолжает [первую серию](openai-experiment.md). Один прогон означает выполнение одной задачи выбранной моделью с одним способом памяти.

Продолжение проверяет, меняется ли результат методов при более сильной модели. Использованы те же 48 примеров, промпты и лимиты. Выполнены 174 дополнительных прогона. Расход с отладкой — $18,49891720. Обеих серий — $27,87631429 из $28.

[Результаты продолжения](../../examples/openai-strong-20261101/report.md) · [Единый отчёт](../reports/final/report.html).

## Назначенные прогоны

| Профиль | Состав | Прогоны |
| --- | --- | --- |
| Sol low | Вся прежняя выборка, с двумя контролями на PersonaMem | 128 |
| Astra low | Девять пар смен цели и десять последних окон PersonaMem | 28 |
| Sol medium | 16 последних окон и два полных контекста PersonaMem | 18 |

Sol low получает память 512, состояние 512, окно 8192, фрагмент 2048 и выход 2048. Полный контекст использует окно 65536. Low сохранён для сравнения с предыдущей серией. Low и medium обозначают выбранный режим внутреннего рассуждения модели. Medium относится только к одношаговым контролям. Весь цикл памяти с ним не повторялся.

## Правило допуска Astra

Очередь задана заранее. Сначала идут смены цели, затем BABILong и PersonaMem. Пара Summary/Reflexive допускается при остатке, покрывающем 1,5-кратный пересчёт токенов Sol по тарифам Astra плюс $0,15. Каждый физический запрос дополнительно проверяется общим бюджетом.

После остановки пар проверяется возможность одношаговых контролей. Сначала рассматривается полный контекст, затем последнее окно, в порядке идентификаторов задач. Запуск возможен только при наличии полного резерва. Последний допустимый остаток использован для более дешёвых контролей Sol medium. Правильность новых ответов не используется при допуске. Решения сохранены в [admissions.json](../../examples/openai-strong-20261101/admissions.json).

## Сравнение и ограничения

Astra не прошла весь набор. Модели сравниваются только на пересечении ID. Совпадение 9/9 не доказывает равенство на других задачах. Это продолжение на прежних eval-примерах, не новый независимый тест. У Sol и Astra сохранены недатированные ID, поэтому точные веса для будущего повторения не зафиксированы.

В расчётах использованы следующие исторические ставки за миллион токенов.

| Модель | Вход | Cached input | Cache write | Выход |
| --- | --- | --- | --- | --- |
| gpt-6.1-sol | $2,00 | $0,10 | $2,50 | $10,00 |
| gpt-6-astra | $10,00 | $1,00 | $12,50 | $50,00 |

Ставки относятся к протоколу от 1 ноября 2026 года. Запись в кеш учитывается по полной ставке, не как двойная плата за тот же токен. Reasoning включён в выход. При редактуре актуальность внешних тарифов не проверялась.

## Воспроизведение

Модуль `context_memory.strong_study` использует фазы prepare, sol, astra, controls и medium-controls. Для них нужны inputs и бюджетный журнал первой серии. Оценка выполняется модулем `context_memory.strong_report`. Полного набора этих локальных файлов в Git нет. Доступен лишь снимок бюджета и сводные материалы.

Сохранённый [protocol.json](../../examples/openai-strong-20261101/protocol.json) содержит Windows-пути к родительской серии и SQLite. На macOS пути нормализуются в отдельной рабочей копии. Исходный протокол сохраняется. Текущий код памяти и промпты совпадают с хешами этой серии.
