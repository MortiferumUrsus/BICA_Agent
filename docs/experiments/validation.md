# Локальная проверка Llama 3.2 1B

9 октября 2026 года проверены демонстрация исправления срока и пять примеров BABILong. Модель не решила BABILong: точность обоих методов 0/5. Summary завершил четыре примера, Reflexive — один; остальные остановлены из-за невалидного формата ответа. Сбоев сети и API не было.

## Условия

Windows, Python 3.11.15, Ollama 0.21.0, GTX 1660 Ti 6 GiB. Модель `llama3.2:1b`, Q8_0, digest и параметры находятся в [local-runtime.json](local-runtime.json). Приложение использовало окно 4096, память 512, состояние 256, фрагмент до 1024 и выход 768 токенов cl100k_base. Окно Ollama — 8192 нативных токена.

BABILong: qa1/8k, строки 5–9, вопрос известен до чтения. [Манифест](../../examples/babilong-manifest.json) фиксирует ревизию и хеш.

## Результаты

| Показатель | Summary | Reflexive |
| --- | --- | --- |
| Запрошено | 5 | 5 |
| Завершено | 4 | 1 |
| Верно | 0 | 0 |
| Остановки из-за формата | 1 | 4 |
| Ошибки API и сети | 0 | 0 |
| Максимум памяти | 252 | 275 |
| Максимум запроса с резервом | 2451 | 2765 |
| Сжатия | 37 | 11 |
| Поиски | 4 | 1 |
| Повторное чтение, токены | 5120 | 2048 |
| Запросы | 51 | 46 |
| Нативные токены | 53475 | 46890 |
| Сумма времени запросов, с | 237,97 | 308,15 |

Все завершённые ответы имели статус insufficient_data. Среди ошибок формата — повторяющиеся ID источников. Последняя корректная память сохранялась. Меньшее число вызовов Reflexive связано с ранними остановками, поэтому его нельзя интерпретировать как экономию при решённой задаче.

В короткой демонстрации исправленный срок появился в памяти, но оба метода также вернули insufficient_data. Это показывает, что сохранённого факта недостаточно: модель должна ещё корректно использовать его при ответе.

## Что подтверждает проверка

136 автоматических тестов той версии прошли. [Сохранённый аудит](validation-audit.json) проверяет порядок фрагментов и ограничения; все 97 запросов учтены. Полный исходный текст сохранён для завершённых примеров. У остановленных прогонов сохранён прочитанный префикс, а не вся история.

Результат относится к этой модели и конфигурации. Оснований выбирать один метод памяти по пяти неудачным примерам нет. Платные API не использовались.
