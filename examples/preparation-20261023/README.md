# Подготовка версии 0.2

- [readiness.json](readiness.json) — результаты проверки программы: 167 тестов, сборка wheel, чтение полного debug-примера PersonaMem в обоих режимах с mock-клиентом и независимая оценка.
- [smoke-mock.json](smoke-mock.json) — короткое обновление факта в двух режимах.
- [personamem-manifest.json](personamem-manifest.json) — revision, хеши исходных файлов и раздельных экспортов, номера строк debug/eval.
- [personamem-plan.json](personamem-plan.json) — подготовленный план пяти eval-вопросов без вызовов модели. Минимальная оценка — 580 вызовов; в ней не учтены поиск, исправления формата и дополнительное дробление.

Качество Qwen или другой новой модели на этом этапе не измерялось. Фоновый запуск Ollama был отклонён автоматической проверкой команд без пояснения причины. Команды ручного запуска приведены в [инструкции](../../docs/testing.md).
