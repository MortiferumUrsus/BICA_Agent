# Подготовка PersonaMem

23 октября 2026 года подготовлены данные и проверен полный путь от чтения истории до отдельной оценки. Новый полноценный запуск реальной модели на этом этапе не выполнялся. Mock проверяет инфраструктуру, а не качество ответов LLM.

| Файл | Что подтверждает |
| --- | --- |
| [readiness.json](readiness.json) | 167 тестов, сборка пакета и полный mock-прогон debug-истории |
| [smoke-mock.json](smoke-mock.json) | Короткое исправление факта в обоих методах |
| [personamem-manifest.json](personamem-manifest.json) | Ревизию, хеши и разделение данных |
| [personamem-plan.json](personamem-plan.json) | План пяти eval-вопросов без генерации |

Нижняя оценка плана — 580 вызовов, без поиска, исправлений формата и дополнительного дробления. Фоновый запуск Ollama тогда был отклонён автоматической проверкой команд. Причины в сохранённом результате нет. [Инструкция ручного запуска](../../docs/guides/testing.md).
